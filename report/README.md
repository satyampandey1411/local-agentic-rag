# Project report

- `Local_Agentic_RAG_Report.pdf` is the report (8 pages; `main.pdf` is the latest build).
- `main.tex` is the editable source: pdfLaTeX, TikZ/pgfplots for the charts.
- `figures/cover.png` is generated by `tools/make_cover.py` (Python + Pillow, Noto fonts):
  `python3 tools/make_cover.py figures/cover.png`.
- `figures/answer_lang.png` is a frame from the demo recording on a free Colab T4; the workflow figure is
  `docs/img/workflow.png`.

Every number in the report comes from a measured run; `docs/RESULTS.md` lists the sources.

## Compile
- This machine: `./build.sh` (pdfLaTeX in the `texlive/texlive` Docker image, 2 passes; the repository root
  is mounted so `docs/img/workflow.png` resolves).
- Overleaf: upload `main.tex`, the `figures/` folder and `docs/img/workflow.png` (into `figures/`), compiler pdfLaTeX.
